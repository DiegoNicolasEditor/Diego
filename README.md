# DYO Studio

Portfólio do Dyo, editor de vídeos. O site é feito em HTML, CSS e
JavaScript e publicado automaticamente pelo GitHub Pages.

## Quer fazer uma alteração?

O passo a passo para atualizar vídeos, depoimentos, contatos e imagens
está em [`leia-me.txt`](./leia-me.txt). Ele foi escrito para quem não
programa.

**Site:** https://digas221960-wq.github.io/dyooo/

## Pastas principais

- `css/` — cores e aparência do site.
- `img/` — fotos, logos e imagens.
- `js/content.js` — vídeos, depoimentos e contatos.
- `js/app.js` — funcionamento do site; normalmente não precisa ser editado.
- `docs/` — informações técnicas. A cópia antiga fica apenas no seu
  computador, em `docs/backups/`, e não é enviada ao GitHub.

Os arquivos `index.html`, `404.html` e as pastas `css/`, `img/` e `js/`
precisam ficar na raiz para o site continuar funcionando.
