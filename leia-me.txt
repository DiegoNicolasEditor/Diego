========================================================
  GUIA PASSO A PASSO — SITE Diego
========================================================

Este guia explica como atualizar o portfólio sem mexer na
programação do site. Leia a parte da alteração que deseja
fazer e siga os passos com calma.


1. ONDE FICA CADA COISA
--------------------------------------------------------

js/content.js
  Vídeos do portfólio, depoimentos, FAQ, contatos e
  informações profissionais. É o arquivo que você vai
  editar com mais frequência.

js/i18n.js
  Textos fixos e traduções para português e inglês.

index.html
  Títulos, parágrafos e textos fixos das seções, incluindo os
  nomes dos programas exibidos no início do site.

img/
  Fotos, logos, imagens de fundo e ícones.

css/variables.css
  Cores, fontes e tamanhos gerais.

css/sections/
  Aparência de cada seção. Evite editar estes arquivos se
  você só quer trocar um vídeo ou texto.

js/app.js
  Funcionamento do site. Não edite para atualizar o conteúdo.

docs/backups/
  Cópias antigas guardadas por segurança. Elas não aparecem
  no site nem são enviadas ao GitHub.

IMPORTANTE: index.html, 404.html, css/, img/ e js/ precisam
ficar na raiz do projeto. Não coloque essas pastas dentro de
outra pasta: o site publicado deixaria de encontrar os arquivos.


2. COMO EDITAR E PUBLICAR PELO GITHUB
--------------------------------------------------------

1. Abra https://github.com/digas221960-wq/dyooo e entre na
   sua conta do GitHub.
2. Abra o arquivo que quer mudar. Por exemplo:
   js/content.js para vídeos, depoimentos e contatos.
3. Clique no ícone de lápis (Edit this file).
4. Faça a alteração com cuidado. Não apague chaves { },
   colchetes [ ], aspas ou vírgulas que fazem parte do código.
5. Confira a alteração e clique em Commit changes.
6. Confirme em Commit changes novamente. O GitHub publica a
   atualização automaticamente pelo GitHub Pages.
7. Aguarde alguns minutos e confira:
   https://digas221960-wq.github.io/dyooo/
   Se ainda aparecer a versão antiga, atualize com Ctrl+F5.

Antes de mexer, você pode abrir o site em outra aba para
comparar. No GitHub, cada alteração confirmada fica salva no
histórico e pode ser recuperada.

Para mudar um arquivo, use o lápis na página dele. Para enviar
uma imagem nova, abra primeiro a pasta certa (por exemplo,
img/testimonials/), escolha Add file > Upload files, selecione
a imagem e confirme com Commit changes.


3. COMO ADICIONAR, TROCAR OU REMOVER UM VÍDEO
--------------------------------------------------------

Abra js/content.js e procure:

  projects: [

Cada bloco entre chaves { ... } é um projeto. Para adicionar
um, copie um bloco inteiro, cole dentro da lista e troque os
dados. Exemplo:

    {
      title: "Nome do meu vídeo",
      youtubeId: "ID_DO_VIDEO",
      category: "Vídeo",
      categoryEn: "Video",
      type: "video",
      format: "horizontal",
    },

Troque "ID_DO_VIDEO" pelo código do vídeo no YouTube. O ID
fica no endereço:

  youtube.com/watch?v=ABC123xyz09  → ID: ABC123xyz09
  youtube.com/shorts/ABC123xyz09   → ID: ABC123xyz09
  youtu.be/ABC123xyz09             → ID: ABC123xyz09

O ID tem 11 letras, números, traços ou sublinhados. Não copie
o endereço inteiro: use somente o ID.

Escolha o tipo e o formato:

  Vídeo vertical (Shorts / Reels / TikTok):
    type: "short"
    format: "vertical"

  Vídeo horizontal (Vídeos Longos / YouTube):
    type: "video"
    format: "horizontal"

Você pode usar vídeos do YouTube através do youtubeId:
  youtubeId: "ID_DO_VIDEO"

Ou arquivos diretos de vÃ­deo (MP4 ou WebM):
  video: "caminho-ou-link-do-video.mp4"
  thumbnail: "caminho-ou-link-da-capa.jpg"

O texto de category é a categoria do vídeo (ex.: "Publicidade",
"Gameplay", "Review"). Ela aparece nos botões de filtro no topo do
player e na legenda do vídeo. Se quiser mostrar a categoria em inglês,
preencha também categoryEn. Esse campo é opcional; sem ele, o site usa
o texto de category nos dois idiomas.

Os players funcionam com efeito 3D (estilo kxeditor):
- Os vídeos tocam diretamente na página com controles de
  reprodução, progresso, volume e tela cheia.
- Navegue entre os projetos pelas setas laterais, clicando nos cartões
  vizinhos, pelos pontos na parte inferior ou deslizando no celular.
Para deixar um projeto antes dos outros, acrescente, por
exemplo, priority: 2, antes do fechamento }. Um número maior
aparece primeiro. Se não usar priority, os projetos mantêm a
ordem normal.

Para trocar um vídeo, mude title, youtubeId e, se necessário,
category, type e format no bloco dele.

Para remover um vídeo, apague o bloco inteiro dele, incluindo
o separador vírgula. Não apague o colchete que fecha a lista
projects: [ ... ].


4. COMO ADICIONAR OU EDITAR UM DEPOIMENTO
--------------------------------------------------------

Em js/content.js, procure:

  testimonials: [

Cada depoimento usa estes campos:

    {
      name: "Nome do cliente",
      handle: "@usuario",
      role: "Profissão ou empresa (opcional)",
      rating: 5,
      quote: "Texto autorizado pelo cliente.",
      avatar: "img/testimonials/nome-da-foto.webp",
    },

Troque o nome, o usuário e a frase. Escolha rating entre 1 e 5;
as estrelas do cartão acompanham essa nota. Inclua role para mostrar
a profissão/empresa no lugar do usuário. Use quoteEn para definir
uma tradução em inglês. Se deixar vazio ou não incluir, a frase em
português será usada nos dois idiomas. O handle é opcional; se
não quiser mostrar um, use handle: "".

Para usar uma foto, envie o arquivo para img/testimonials/ e
escreva o caminho e o nome exatos em avatar. Se não tiver foto,
use avatar: "". O site mostrará as iniciais do nome.

Peça autorização antes de publicar o nome, a foto ou a frase de
um cliente. As fotos de clientes que já estão no site são reais;
não as substitua por imagens inventadas.

Para remover um depoimento, apague somente o bloco dele.

Com mais de um depoimento, o site mostra os cartões em uma
faixa horizontal que avança sozinha. Use as setas, os pontos
ou arraste para o lado no celular. A animação pausa quando
alguém passa o mouse ou navega pelos controles.


5. COMO TROCAR OS LINKS DE CONTATO
--------------------------------------------------------

Em js/content.js, procure:

  contactLinks: {

Edite o endereço que está entre aspas, sem apagar o nome do
campo. Exemplos:

  whatsapp: "https://wa.me/5521984315865",
  instagram: "https://www.instagram.com/seuusuario",
  x: "https://x.com/seuusuario",
  tiktok: "https://www.tiktok.com/@seuusuario",
  primary: "https://wa.me/5521984315865",

No WhatsApp, use o código do Brasil 55 e o número com DDD,
somente números: sem +, espaços ou parênteses. O campo primary
é o destino do botão principal "Entrar em contato".


6. COMO MUDAR TEXTOS E INFORMAÇÕES DO PERFIL
--------------------------------------------------------

Para alterar um título ou parágrafo que aparece na página,
edite o texto dentro de index.html, sem apagar as tags como
<p>, <h2> e </p>.

Para adicionar informações profissionais opcionais, edite
profileDetails em js/content.js. Cada informação tem um rótulo
e um texto:

  profileDetails: [
    { label: "Experiência", text: "Sua informação verdadeira" },
  ],

Se não quiser mostrar essas informações, deixe:

  profileDetails: [],

Não publique dados pessoais que você não queira deixar
públicos na internet.


7. COMO EDITAR O FAQ E OS IDIOMAS
--------------------------------------------------------

As perguntas e respostas ficam em faq, no arquivo
js/content.js. Cada item usa q para a pergunta e a para a
resposta. Para mostrar a tradução em inglês, preencha também
en:

  {
    q: "Sua pergunta em português?",
    a: "Sua resposta em português.",
    en: {
      q: "Your question in English?",
      a: "Your answer in English.",
    },
  },

Os textos fixos da página e suas traduções ficam em
js/i18n.js. Cada texto tem uma versão pt e outra en. O site
abre em português por padrão; use o botão PT | EN no cabeçalho
para trocar o idioma. A escolha fica salva para as próximas
visitas. Para adicionar ou editar um texto, mantenha as duas
versões juntas na mesma chave.


8. COMO TROCAR UMA FOTO
--------------------------------------------------------

Para trocar uma foto mantendo o mesmo uso no site, envie a nova
imagem para a mesma pasta e mantenha exatamente o mesmo nome do
arquivo antigo. Assim o site continua encontrando a imagem sem
alterar o código.

Fotos e logos da marca: img/brand/
Fotos de depoimentos: img/testimonials/
Imagem guardada da seção "Sobre": img/sections/
Fundo do contato: img/backgrounds/
Imagem de compartilhamento: img/social/

ATENÇÃO: img/brand/foto-dyo.webp é uma foto real da marca, mas
ela não é exibida na seção "Sobre" atualmente. Não apague nem
substitua essa foto por uma imagem gerada.

Não apague foto, logo ou ícone sem saber onde ele é usado.
Mantenha uma cópia da imagem antiga antes de substituí-la.


9. COMO MUDAR AS CORES
--------------------------------------------------------

As cores e tamanhos principais ficam em css/variables.css.
Se for alterar, mude apenas o valor do token desejado e teste
as seções claras e escuras. Não coloque cores diretamente nos
arquivos css/sections/: o site usa variáveis compartilhadas.


10. REGRAS PARA NÃO QUEBRAR O SITE
--------------------------------------------------------

- Edite só o que precisa; não apague linhas que não entende.
- Em js/content.js, mantenha aspas, chaves, colchetes e vírgulas.
- Use o ID do YouTube, não o link completo, em youtubeId.
- Confira se o nome e o caminho de cada imagem estão corretos.
- Não mova index.html, 404.html, css/, img/ ou js/.
- Não edite js/app.js para trocar conteúdo.
- Salve e publique pelo botão Commit changes do GitHub.
- Depois da publicação, abra o site e confira a alteração.

Se algo ficar errado, não faça várias mudanças de uma vez.
Volte ao arquivo no GitHub, compare com o histórico da última
alteração e corrija só o trecho com problema.
